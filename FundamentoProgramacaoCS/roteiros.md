# .NET Developer Roadmap

> ⚠️ **Observação importante:** Este roadmap é destinado a pessoas que **já possuem conhecimentos básicos de programação**.

O objetivo deste material não é ensinar programação do zero. Por isso, conceitos fundamentais como:

* O que é uma variável;
* Tipos de dados;
* Tipos primitivos;
* `if` / `else`;
* `for` / `while`;
* Operadores;
* Entrada e saída de dados;
* Conceitos básicos de lógica de programação;

não serão explicados detalhadamente.

É esperado que você já tenha uma noção desses conceitos e consiga compreender uma estrutura básica de código.

A proposta aqui é **aprofundar esses conhecimentos utilizando C# e o ecossistema .NET**, avançando gradualmente para o desenvolvimento de aplicações reais.

Durante o roadmap, serão abordados conceitos como:

* Programação Orientada a Objetos com C#;
* LINQ;
* Programação assíncrona;
* .NET;
* ASP.NET Core;
* APIs REST;
* SQL Server;
* Entity Framework Core;
* Autenticação e autorização;
* Testes automatizados;
* Docker;
* Boas práticas de desenvolvimento.

> 💡 **A ideia deste repositório é servir como uma documentação pública do meu processo de aprendizado.**
> Os conteúdos serão desenvolvidos de forma prática, com exemplos de código, exercícios, problemas encontrados durante o desenvolvimento e explicações dos conceitos estudados.

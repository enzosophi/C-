# 🚀 .NET Developer Roadmap

> Um curso/roadmap público criado para estudar, praticar e documentar minha evolução como desenvolvedor .NET.

Este repositório foi criado com o objetivo de organizar meus estudos de **C#, .NET e desenvolvimento Backend**, transformando meu processo de aprendizado em uma documentação que também possa ajudar outras pessoas que estejam estudando a mesma área.

A proposta é simples:

**Aprender → Praticar → Documentar → Ensinar → Evoluir**

---

## 🎯 Objetivo

Meu objetivo com este roadmap é desenvolver uma base sólida para atuar profissionalmente como **Desenvolvedor .NET**, estudando desde os fundamentos da linguagem até conceitos utilizados em projetos reais.

Durante o desenvolvimento deste repositório, vou criar exemplos, exercícios e projetos práticos para colocar cada conceito em prática.

---

## 👨‍💻 Para quem é este conteúdo?

> ⚠️ **Pré-requisito:** este conteúdo não é voltado para quem está começando do zero em programação.

É recomendado possuir conhecimentos básicos de:

* Lógica de programação
* Variáveis e tipos de dados
* Estruturas condicionais
* Estruturas de repetição
* Funções/métodos
* Arrays e coleções
* Conceitos básicos de programação

A ideia aqui é focar nos **conceitos específicos do ecossistema C#/.NET**, sem gastar muito tempo explicando fundamentos gerais de programação.

# 📖 Como utilizar este repositório

Cada módulo possui seu próprio `README.md`, contendo explicações e exemplos.

A ideia é estudar os conceitos na ordem:

```text
Teoria
  ↓
Exemplo
  ↓
Prática
  ↓
Exercício
  ↓
Projeto
```

Os códigos presentes no repositório não têm apenas o objetivo de funcionar. Eles também servem como **material de estudo**, com explicações sobre os conceitos utilizados.
